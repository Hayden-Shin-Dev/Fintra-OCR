# Fintra Studio

문서 업로드부터 추출값 확인, 거래 비교, 검토조서 작성까지 이어지는 웹 서비스입니다.
챗봇은 현재 거래의 근거를 바탕으로 차이와 확인할 절차를 설명합니다.

기존 Fintra 런타임이 설치된 Windows에서 `Start-Fintra.cmd`로 실행합니다.
팀 테스트는 `Start-Team-Preview.cmd`로 시작하고, 생성된 `team-preview/access.txt`에서 URL을 확인하면 됩니다.
