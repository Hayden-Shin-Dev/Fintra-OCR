# 공개 저장소 점검 기록

점검일: 2026-10-01

## 공개 범위

이 저장소는 신민철의 Fintra 포트폴리오입니다. 자체 코드와 문서는 권리를 유지하며, 일반적인 상업 이용이나 재배포를 허용하는 오픈소스 라이선스를 부여하지 않습니다. GitHub 약관에 따른 열람과 포크 및 법령상 권리는 제한하지 않습니다. [LICENSE](../LICENSE)에 범위를 명시했습니다.

실행 중인 서버의 계정 DB나 업로드 자료를 공개 저장소로 복사하지 않았습니다. 별도 설치형 런타임, 모델 가중치, 회계기준 코퍼스는 배포 범위 밖입니다. 전체 서비스는 저장소 복제만으로 실행되지 않으며, 재현 범위는 [실행 문서](SETUP.md)에 구분합니다.

## 실제 확인한 내용

| 토크나이저 출처 | Git 원본의 SHA-256과 SOURCES.md 기록 비교 | 일치 |

| Git 이력 | 복제 시점의 모든 원격 브랜치에서 도달 가능한 파일 객체 1,251개에 인증키 패턴 검사 | 해당 패턴 탐지 없음 |
| OCR 코드 | Python 3.10.5에서 `python -m pytest -q` | 304개 통과, 테스트 클라이언트 의존성의 폐기 예정 경고 1개 |
| 회계기준 수집 | `kasb_sync.rights_for()` 코드 확인 | 이용 근거 및 다운로드, 인덱싱, 서비스 이용 확인값 요구 |

| 배포 메타데이터 | `pip wheel . --no-deps --no-build-isolation` | 빌드 성공, 자체 LICENSE와 토크나이저 LICENSE 포함 확인 |
| 문서 링크 | README, SOURCES, 외부 고지와 docs의 로컬 Markdown 링크 확인 | 깨진 로컬 링크 없음 |

인증키 검사는 GitHub 토큰, AWS 접근키 식별자, 일부 모델 제공자 키 형식, 개인키 헤더를 대상으로 합니다. 비밀번호 전수 탐지, 개인정보 의미 분석, 보안 취약점 감사 또는 유출 부재 증명은 아닙니다. 삭제된 원격 참조나 다른 저장소의 복사본까지 검사한 것은 아닙니다. OCR 단위 테스트 통과는 OCR 정확도 90%나 실제 모델의 답변 품질을 뜻하지 않습니다.

재실행:

```powershell
python scripts/audit_repository.py --history
python -m pytest -q
```

추가한 GitHub Actions는 공개 파일 검사와 OCR 테스트를 실행합니다. 모델 추론, 설치형 Studio 전체 통합 테스트와 외부 서비스의 가용성을 검증하는 작업은 아닙니다.

## 운영이나 재배포 전에 별도로 확인할 사항

1. KASB 및 IFRS 자료를 실제 서비스에서 수집, 인덱싱하거나 답변에 제공하려면 해당 이용 범위에 맞는 권리 근거가 필요합니다. 저장소 안의 설정과 출처 표기는 이용 허락을 대신하지 않습니다. 이번 점검에서 별도 계약이나 허가서는 확인하지 않았습니다.
2. 실행 프로그램이나 모델을 묶어 배포할 경우 실제 설치 버전과 전이 의존성, 모델 배포본을 기준으로 라이선스와 고지를 다시 확인해야 합니다. 현재 문서는 공개 소스 저장소에 대한 기록입니다.
3. 대표 이미지는 AI로 제작한 소개 이미지입니다. 실제 화면이나 측정 결과로 제시하지 않으며, 생성물의 독점적 저작권을 보장하지 않습니다.
4. 실제 고객 증빙이나 기업 내부 데이터를 공개 체험에 넣지 않습니다. 화면 캡처를 새로 추가할 때에도 사용자 계정과 거래 정보가 들어 있지 않은지 확인합니다.

이 기록은 기술적인 확인 범위와 남은 조건을 설명하며, 모든 법률상 권리가 정리되었다는 보증이나 법률 의견이 아닙니다.
