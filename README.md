# Fintra

물류와 무역 거래의 증빙을 검토하는 AI 회계감사 보조 프로젝트입니다.
송장, 포장명세서, 선하증권과 장부를 일일이 맞춰 보는 작업을 줄여보려고 만들었습니다.

문서를 올리면 OCR로 읽은 값을 원본과 함께 확인하고, 거래별 금액, 수량, 날짜 등을 비교할 수 있습니다. 차이가 있는 항목은 챗봇에 물어보고, 관련 회계기준과 확인할 내용을 참고해 검토조서 초안을 작성합니다. 마지막에는 사람이 내용을 확인하고 수정합니다.

- `fintraocr/` — 문서 인식과 필드 추출
- `studio/` — 문서 업로드, 거래 비교, 챗봇, 검토조서 웹 화면
- `tests/`, `studio/tests/` — 기능 및 회귀 테스트

현재는 로컬 실행과 팀 테스트용으로 사용하고 있습니다. 웹 서비스는 별도 Fintra 런타임이 필요합니다.
